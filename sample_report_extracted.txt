3.4.1. Unit-тестирование
Одним из наиболее важных методов в разрабатываемом программном обеспечении является метод, который возвращает список свободных временных интервалов (заданного размера) в графике сотрудника для формирования оптимального графика работы сотрудников. Именно для этого метода мной были составлены unit-тесты.
Сам класс расчета свободных промежутков времени выглядит следующим образом:
public class Calculations
{
public List<string> AvailablePeriods(TimeSpan[] startTimes,
int[] durations, TimeSpan beginWorkingTime, TimeSpan endWorkingTime,
int consultationTime)
{
if (startTimes[0] < beginWorkingTime) throw new Exception("Запись не может быть раньше начала рабочего дня");
if (startTimes[4] > endWorkingTime) throw new Exception("Запись не может быть позже конца рабочего дня");
for (int i=1; i<startTimes.Length; i++) if (startTimes[i]<= startTimes[i-1]) throw new Exception("Записи должны быть отсортированы");
if (beginWorkingTime>=endWorkingTime) throw new Exception("Начало рабочего дня не может превышать конца рабочего дня");
if(consultationTime<= 0) throw new Exception("Время консультации должно быть числом положительным");
for (int i = 0; i < durations.Length; i++) if (durations[i] <= 0) throw new Exception("Время записи не могло быть отрицательным");
if (startTimes.Length != durations.Length) throw new Exception("Несовпадение размеров списка записей и их длительностей");
if (startTimes[4].Add(TimeSpan.FromMinutes(durations[4])) > endWorkingTime) throw new Exception("Запись не может выходить за пределы рабочего времени");
for (int i = 1; i < startTimes.Length; i++) if (startTimes[i] < startTimes[i - 1].Add(TimeSpan.FromMinutes(durations[i-1]))) throw new Exception("Записи пересеклись");
List<string> MyList = new List<string>();
TimeSpan CountTimes = beginWorkingTime.Add(TimeSpan.FromMinutes(consultationTime));
for (int i =0; i < startTimes.Length; i++)
{
while (CountTimes <= endWorkingTime)
{
if (startTimes[i] >= beginWorkingTime && startTimes[i] < CountTimes)
{
beginWorkingTime = startTimes[i].Add(TimeSpan.FromMinutes(durations[i]));
CountTimes = beginWorkingTime.Add(TimeSpan.FromMinutes(consultationTime));
break;
}
else
{
MyList.Add(beginWorkingTime.ToString(@"hh\:mm") + "-" + CountTimes.ToString(@"hh\:mm"));
beginWorkingTime = CountTimes;
CountTimes = CountTimes.Add(TimeSpan.FromMinutes(consultationTime));
}
}
}
while (CountTimes <= endWorkingTime)
{
MyList.Add(beginWorkingTime.ToString(@"hh\:mm") + "-" + CountTimes.ToString(@"hh\:mm"));
beginWorkingTime = CountTimes;
CountTimes = CountTimes.Add(TimeSpan.FromMinutes(consultationTime));
}
return MyList;
}
}
Из данного класса видно, что на вход он принимает 5 аргументов: массив из промежутков начал записей, массив их длительностей, начало рабочего времени, конец рабочего времени, время консультации с сотрудником.
Класс Calculations выбрасывает исключения в следующих случаях:
пользователь пытается осуществить запись к сотруднику раньше начала его рабочего времени,
пользователь пытается осуществить запись к сотруднику позже окончания рабочего времени,
на вход подается список записей в неотсортированном виде,
время начала рабочего времени превышает конец рабочего времени,
время консультации число не положительное,
в списке записей хотя бы одна из длительностей консультации не положительная,
несовпадение размеров списка записей и их длительностей,
запись выходит за пределы рабочего времени,
записи к сотруднику пересеклись по времени.
В случае если исключений не возникло метод возвращает список свободных для записи промежутков времени. Десятый unit-тест проверяет корректно ли возвращается данный список.

1.Студент очень быстро распознает различные взаимосвязи объектов, рабочих и технологических процессов (обширные специальные знания)
