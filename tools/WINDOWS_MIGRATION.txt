Отдельный репозиторий только для OxygenStore (без всего OneDrive)
================================================================

Проблема
---------
Раньше папка .git лежала на уровне всего каталога OneDrive, из-за этого в git попадали посторонние файлы, а команды вроде "git add ." были опасны.

Что сделано
-----------
Создан новый репозиторий (снимок дерева проекта из последнего коммита monorepo):

  C:\Users\nazar\diplom-standalone-export

Внутри уже выполнены:
  git init
  git add -A
  git commit  (один корневой коммит)
  git branch -M main
  git remote add origin https://github.com/nazar2210/diplom.git

Почему не перенесли «полную историю» автоматически
-------------------------------------------------
На Windows команда `git subtree split` с кириллическим путём падает с ошибкой assertion в самом git (известный класс проблем с кодировкой).

Если история критична — установите git-filter-repo и перепишите историю в отдельной копии (см. https://github.com/newren/git-filter-repo).

Как отправить на GitHub
-----------------------
Откройте PowerShell:

  cd C:\Users\nazar\diplom-standalone-export
  git push -u origin main --force

Флаг --force нужен, потому что на GitHub уже есть другая история коммитов (старый monorepo). Это ПЕРЕЗАПИШЕТ историю репозитория nazar2210/diplom под новый корень проекта.

Если не хотите ломать старый remote — создайте НОВЫЙ репозиторий на GitHub и замените URL:

  git remote set-url origin https://github.com/<user>/<new-repo>.git
  git push -u origin main

После успешного push
--------------------
1. В Cursor откройте папку C:\Users\nazar\diplom-standalone-export как проект.
2. Старый проект на рабочем столе можно оставить как резерв, пока не убедитесь, что всё ок.
3. Старый .git в OneDrive лучше не трогать, пока не перенесёте все нужные вещи.
