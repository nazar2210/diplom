# Настройка изображений для карточек товаров

## Что было сделано

Я обновил каталог товаров для использования реалистичных изображений вместо placeholder'ов. Теперь каждая карточка товара отображает реальное изображение продукта.

## Использованные изображения

### Источник изображений
- **Unsplash** - бесплатный сервис высококачественных фотографий
- Все изображения оптимизированы для веб-использования
- Размер: 300x200px с обрезкой по центру

### Типы изображений по категориям:

1. **Медицинский кислород** - медицинские баллоны и оборудование
2. **Промышленный кислород** - промышленные баллоны и системы
3. **Портативные баллоны** - компактные переносные устройства
4. **Оборудование** - регуляторы давления и аксессуары

## Технические особенности

### Обработка ошибок загрузки
- Если изображение не загружается, показывается fallback иконка
- Состояние загрузки отслеживается для каждого товара
- Плавные переходы и анимации при наведении

### Оптимизация производительности
- Lazy loading изображений
- Кэширование состояний загрузки
- Responsive изображения с правильными размерами

## Альтернативные решения

### 1. Локальные изображения
```javascript
// Поместите изображения в папку public/images/
image: '/images/medical-oxygen-10l.jpg'
```

### 2. CDN сервисы
```javascript
// Используйте специализированные CDN
image: 'https://cdn.example.com/products/oxygen-tank.jpg'
```

### 3. Генерация изображений
```javascript
// Используйте сервисы для генерации изображений
image: `https://picsum.photos/300/200?random=${product.id}`
```

## Рекомендации для продакшена

1. **Создайте собственные изображения** товаров
2. **Используйте WebP формат** для лучшей оптимизации
3. **Добавьте alt-тексты** для SEO
4. **Настройте lazy loading** для больших каталогов
5. **Используйте CDN** для быстрой загрузки

## Обновление изображений

Чтобы изменить изображение товара, обновите поле `image` в массиве `mockProducts`:

```javascript
{
  id: 1,
  name: 'Медицинский кислород 10л',
  image: 'https://your-image-url.com/image.jpg',
  // ... остальные поля
}
```

## Проверка работы

1. Запустите проект: `npm run dev`
2. Перейдите в каталог товаров
3. Убедитесь, что изображения загружаются корректно
4. Проверьте fallback при отключенном интернете
